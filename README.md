# MySQL — Beginner to Advanced

A hands-on SQL learning repository documenting my journey through MySQL, from fundamental queries to advanced SQL concepts, with dedicated projects for data cleaning and exploratory data analysis.

## Projects

### 1. Data Cleaning Project
Practical SQL exercises focused on inspecting datasets, identifying data quality issues, and preparing data for analysis.

### 2. Exploratory Data Analysis
A SQL-based project focused on exploring data, summarizing results, and identifying patterns using analytical queries.

## SQL Concepts Covered

- **SQL Fundamentals:** SELECT, WHERE, ORDER BY, LIMIT, and column aliasing
- **Data Aggregation:** GROUP BY, HAVING, and aggregate functions
- **Conditional Logic:** CASE statements
- **Combining Data:** JOINs and UNION
- **Advanced Queries:** Subqueries and Common Table Expressions (CTEs)
- **Temporary Storage:** Temporary tables
- **Analytical SQL:** Window functions
- **Database Programming:** Stored procedures, triggers, and events
- **String Operations:** String functions
- **Database Setup:** Creating databases using SQL scripts
